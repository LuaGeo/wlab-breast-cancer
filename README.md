# Wlab — Prédiction du Cancer du Sein

Application Streamlit prédisant la nature (bénigne / maligne) d'une tumeur mammaire à partir des caractéristiques mesurées sur biopsie.

🚀 **Démo en ligne** : [wlab-breast-cancer.streamlit.app](https://wlab-breast-cancer.streamlit.app)

## Stack

- Python · Streamlit · scikit-learn · NumPy
- Modèle entraîné sur le Wisconsin Breast Cancer Dataset

## Lancer en local

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Avertissement

Projet pédagogique — ne remplace pas un diagnostic médical professionnel.
